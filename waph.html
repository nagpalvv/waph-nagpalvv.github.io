Course Overview

I took this course to learn how to build applications and add security for the things I build, including websites and machine learning models.

Hands-on Exercises: Labs

  • Lab 0 - Development Environment Setup: Set up an Ubuntu 22.04 Virtual Machine on VirtualBox, installed software like Apache and pandoc, and configured SSH keys for private and public GitHub repositories.
  • Lab 1 - Foundations of the Web: Explored HTTP protocols using Wireshark, Telnet, and curl. Built basic CGI programs in C and PHP, and identified Cross-Site Scripting (XSS) vulnerabilities.
  • Lab 2 - Front-end Web Development: Developed front-end interfaces using HTML, CSS, and JavaScript. Implemented Ajax and jQuery for background requests, and integrated public APIs (Joke API, Agify API) using modern fetch() protocols.

Hands-on Exercises: Hackathons

  • Hackathon 1 - Cross-site Scripting Attacks and Defenses: Performed reflected cross-site scripting (XSS) attacks across multiple server levels. Applied defensive coding to previous lab applications by validating untrusted input and encoding data before display.

Course Projects

  • Individual Project 1: Creating and deploying a professional front-end profile website on github.io using CSS frameworks, Web APIs, and JavaScript cookies.
  • Individual Project 2: Secure full-stack web application development.
  • Team Project: Development of a miniFacebook application incorporating comprehensive web security implementations.
